# "onde" la yoly — versión Supabase

Esta versión conecta reservas y reseñas directamente con Supabase.

## Antes de desplegar
1. En Supabase SQL Editor ejecuta `SUPABASE-RESERVAS-RESENAS.sql` una sola vez.
2. Verifica que la vista `reservas_publicas` exista.
3. Sube el contenido de este ZIP a tu repositorio de GitHub conectado a Vercel.

Las fotos siguen usando Storage `gallery`.
